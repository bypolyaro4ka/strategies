# Стратегии Славы — портированы из Freqtrade

Оригиналы — Freqtrade `IStrategy` (talib), портированы 1:1 в наш интерфейс `BaseStrategy`.

## sol_frozen_v2 (`SlavaSolFrozenV2`)
**Идея.** Пробой EMA5 вверх через EMA30 при растущем EMA30, подтверждённый объёмом и
сильным телом свечи, в мягком бычьем режиме (EMA200 не падает резко).
**Правило:** вход — `EMA5×EMA30 cross up` + `EMA30_slope6>0` + `volume>SMA30(volume)` +
`body_ratio≥0.65` + `ret24<3%` + `EMA200_slope72>-2%` + `ret72<8%`. Стоп фиксированный −25%.
Выход: минимум 64ч держим, максимум 144ч, между ними — выход, если EMA30 перестал расти
(сравнение с 6ч назад).
**ТФ:** 1h. **Направление:** только лонг.

## eth_strong_breakout_v1_emergency (`SlavaEthStrongBreakout`)
**Идея.** Свежий пробой 168-часового максимума силой ≥1.25 ATR(14) в восходящем режиме
(EMA50>EMA200).
**Правило:** вход — первый бар пробоя (`close > max(high[t-168..t-1])`), сила пробоя
`(close-prev_high_168)/ATR14 ≥ 1.25`, `EMA50>EMA200`. Выход — фиксированно через 72ч,
аварийный стоп −15%.
**ТФ:** 1h. **Направление:** только лонг.

## c2_local_compression (`SlavaC2LocalCompression`)
**Идея.** Сжатие волатильности (ATR% ниже медианы, локальный диапазон намного меньше
макро-диапазона) + сильный бычий пробой локального максимума, всё ещё внутри макро-контейнера.
**Правило:** сигнал подтверждается, если похожий "сырой" сигнал уже был в предыдущие 72ч.
Регим-фильтр по EMA200 у автора **выключен по умолчанию** (REGIME_MODE=OFF). Выход —
фиксированно через 60ч, либо раньше (36ч) при просадке ≤ −4% от входа ("age failure").
Стоп −12%.
**ТФ:** 1h. **Направление:** только лонг.

## Отличия порта от оригинала
- Freqtrade считает `current_profit` через биржевые котировки в реальном времени; здесь —
  `close_t / avg_entry_price − 1`, эквивалент на баре сигнала.
- `custom_exit` у автора проверяется на каждой минуте между барами; наш движок проверяет
  решения только на закрытии сигнального бара (1h) — на этом ТФ разницы по факту нет,
  так как `age_hours` считается в целых часах.
