# Стратегии Коли — 9 семейств (без oi_impulse, ждёт данных по open interest)

Общая механика исполнения (см. докстринг `strategies.py`): вход на open бара после сигнала,
выход — по стопу/тейку/трейлингу/max_bars сигнальных баров. Направление long/short, ТФ — 1h.

| Класс | Идея | Выход |
|---|---|---|
| `KolyaBreakout` | Донche breakout 20 + подтверждение объёмом | trailing-стоп 3×ATR |
| `KolyaMeanReversion` | Z-score по Боллинджеру + RSI, только при падающей волатильности | возврат к средней полосы, либо стоп 1.5×ATR |
| `KolyaEmaPullback` | Откат к EMA20 в тренде (EMA50 vs EMA200), разворотная свеча | стоп 2×ATR / тейк 3×ATR |
| `KolyaVolatilityBreakout` | Сжатие (Боллинджер+ATR% в нижних 20% истории) + пробой с объёмом | trailing-стоп 2.5×ATR |
| `KolyaFundingContrarian` | Экстремальный фандинг (квантили 90/10 за 60 отметок) + разворотная свеча через EMA | стоп 2×ATR / тейк 3×ATR. **Требует колонку `funding_rate` в bars** |
| `KolyaLiquidationSweep` | Длинная свеча с большим фитилём за пределы диапазона 20 баров + объём | стоп = сам экстремум свечи / тейк 2×ATR |
| `KolyaKeltnerSqueeze` | Сжатие Боллинджера внутри канала Кельтнера + пробой с объёмом | trailing-стоп 3×ATR |
| `KolyaRsiTrendContinuation` | RSI(14) пересекает 50 (или 50 снизу для шорта) в тренде EMA50/200 | стоп 2×ATR / тейк 3×ATR |
| `KolyaMacdTrend` | MACD-гистограмма меняет знак в тренде EMA50/200 | стоп 2×ATR / тейк 3×ATR |

Все параметры — базовые значения из кода автора (`config/strategies.json`,
`scripts/run_advanced_strategies.py`, `scripts/run_market_structure_strategies.py`,
`scripts/search_new_candidates.py`), **не** его пост-фактум отобранные комбинации — см.
`DECLARATION.md`.

## Отличия порта от оригинала
- У автора — одна позиция на весь депозит (`Single-position, all-in backtest`), фиксированный
  учёт fee/slippage в б.п. Здесь — стандартная модель лаборатории (`target`, `slot_fraction`,
  издержки протокола) — числа с оригинальным бэктестом автора несравнимы напрямую.
- Трейлинг-стоп у автора считается по `previous.atr`/`previous.trail_atr` (данные закрытого
  бара) — здесь стоп пересчитывается в `on_bar` на закрытии бара и проверяется движком на
  следующем баре, тот же эффект без явного сдвига.
