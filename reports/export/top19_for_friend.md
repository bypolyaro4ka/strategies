## Правила стратегий

Все окна/индикаторы считаются по закрытым барам; текущий (последний) бар в rolling-окна
не входит, если не указано иное. RSI/ATR/ADX — по Уайлдеру (`ewm(alpha=1/n)`), EMA —
`ewm(span=n)`, std в Боллинджере — `ddof=0`.

### 1. S13 — Кросс-секционный моментум (Леша)
**Источник идеи:** Liu, Tsyvinski, Wu (2022), кросс-секционный моментум крипто-активов.
**Режим:** только портфельный (ранжирует весь пул сразу), ребаланс раз в неделю
(решение по закрытию воскресного дневного бара, исполнение в понедельник 00:00 UTC).
**Правило:** `score_i = close[t-skip] / close[t-L] - 1` для каждой монеты пула с полной
историей L. Лонг — k монет с лучшим score (target +1 каждой), шорт — k худших
(target -1), остальные 0. Если монет с полной историей меньше 2k — позиций нет.
**Дефолты:** L = 21 день, k = 3, skip = 0. ТФ 1d.

### 2. S05 — Пробой Боллинджера (Леша)
**Идея:** выход цены за полосу Боллинджера — начало движения (трендовая трактовка,
не разворотная).
**Правило:** `mid = SMA(close, n)`, `up = mid + k·std(close, n)`, `dn = mid - k·std(close, n)`.
Лонг: `close_t > up_t` → target +1, выход по `exit_rule`. Шорт — зеркально от `dn`.
`exit_rule = mid`: выход из лонга при `close_t < mid_t` (выход из шорта при `close_t > mid_t`).
**Дефолты:** n = 20, k = 2, `exit_rule = mid`. ТФ 1d.

### 3. Friend4 Ichimoku RSI (Друг4) ⚠
**Правило:** Tenkan (conversion, период 7) пересекает Kijun (base, период 22) снизу
вверх, цена выше облака (`> max(span_a, span_b)`, span_b период 44), RSI(14) > 50 →
лонг; зеркально — шорт. Выход: Tenkan/Kijun развернулись или цена вернулась в облако
(или под него). Стейтфул автомат — выход проверяется первым, затем в том же баре
возможен вход (включая прямой разворот).
**Параметры:** `conversion_n=7, base_n=22, span_b_n=44, rsi_n=14`. ТФ 1d.

### 4. S01 — Donchian-ансамбль (Леша)
**Источник:** Zarattini, Pagani, Barbon (2025). **Идея:** несколько пробойных моделей
с разными окнами L ∈ {5, 10, 20, 30, 60, 90, 150, 250, 360} дней, итоговая позиция —
доля "включённых" моделей.
**Для каждого L независимо:** `upper_L = max(close[t-L..t-1])`, `lower_L = min(close[t-L..t-1])`,
`mid_L = (upper_L + lower_L) / 2`. Вход (лонг-компонента): компонента выключена и
`close_t > upper_L` → включить, `stop_L = mid_L`. Сопровождение: `stop_L = max(stop_L, mid_L)`
на каждом баре. Выход: `close_t < stop_L` (по закрытию бара, не внутри бара). Если истории
меньше L — компонента выключена.
**Итог:** `raw = n_включённых / 9`. Таргетирование волатильности встроено:
`σ = std(дневные лог-доходности за 90д) × √365`, `scale = min(1, vol_target/σ)`,
`target = raw × scale`.
**Дефолты:** все 9 окон, `vol_target = 0.25`, `vol_window = 90`. ТФ 1d. Только лонг.

### 5. S01b — Donchian-ансамбль, зеркальный шорт (Леша)
То же, что S01, плюс симметричная шорт-компонента для каждого L: вход `close_t < lower_L`,
`stop_L = mid_L`, сопровождение `stop_L = min(stop_L, mid_L)`, выход `close_t > stop_L`.
`raw = (n_лонг - n_шорт) / 9`, размер — как в S01. Дефолты те же, что у S01.

### 6. Slava ETH Strong Breakout (Слава) ⚠
Портирован из Freqtrade `IStrategy` (`EthStrongBreakoutV1Emergency`).
**Правило:** первый бар пробоя 168-часового (7 дней) максимума
(`close_t > max(high[t-168..t-1])`, засчитывается только момент пересечения, не весь
период выше уровня), сила пробоя `(close - prev_high_168) / ATR14 ≥ 1.25`,
режимный фильтр `EMA50 > EMA200`. Выход — фиксированно через 72 часа, аварийный
стоп -15% от входа. Только лонг.
**Параметры:** lookback=168ч, порог силы=1.25×ATR(14), EMA(50)/EMA(200), hold=72ч,
stop=-15%. ТФ 1h.

### 7. Friend4 EMA/ADX Trend (Друг4) ⚠
**Правило (безстейтовое — target = текущее значение индикатора):** `EMA(fast) > EMA(slow)`
и `ADX ≥ threshold` и `+DI > -DI` → target +1 (лонг); зеркально (`EMA(fast) < EMA(slow)`,
ADX≥threshold, `-DI > +DI`) → -1; иначе 0.
**Параметры:** `fast=5, slow=20, period(ADX)=14, threshold=20`. ТФ 1d.

### 8. Friend4 BB Regime Reversion (Друг4) ⚠
**Правило:** возврат к средней Боллинджера (n=20), но вход разрешён только "по режиму":
касание нижней полосы → лонг, только если цена всё ещё выше долгосрочной EMA(100)
(режим не медвежий); симметрично для шорта у верхней полосы (цена ниже EMA(100)).
Выход — возврат цены к средней полосе. Стейтфул автомат (выход проверяется первым, вход
— в том же баре).
**Параметры:** `n=20, mult=1.8, regime_n=100`. ТФ 1h.

### 9. S03 — Цена против SMA (Леша)
**Источник:** Grobys, Ahmed, Sapkota (2020). **Правило:** `sma = mean(close[t-n+1..t])`
(текущее закрытие включено). `close_t > sma×(1+band)` → +1; `close_t < sma×(1-band)` → -1
(режим LS) или 0 (режим LF); внутри полосы — сохранить прошлый target.
**Дефолты:** n=20, band=0, режим LS. ТФ 1d.

### 10. S07 — EMA-кросс (golden/death cross) (Леша)
**Правило:** `EMA_fast > EMA_slow` → +1, иначе -1 (режим LS) или 0 (режим LF).
**Дефолты:** fast/slow = 50/200, режим LS. ТФ 4h.

### 11. S12 — Контртренд по экстремальному фандингу (Леша)
**Идея:** экстремально высокий фандинг — перегруженные лонги (чаще перед падением),
экстремально отрицательный — перегруженные шорты.
**Подготовка фандинга:** нормировка к 8-часовому эквиваленту `f8 = funding_rate × (8/interval_hours)`;
на закрытии 4h-бара используются только отметки фандинга строго раньше момента закрытия
(отметка ровно в момент закрытия — на следующем баре). `z = (f8_last - mean(f8 за 30д)) /
max(std(f8 за 30д), 0.00005)`.
**Правило:** шорт-вход `z > z_in` и `f8_last ≥ 0.0002`; лонг-вход `z < -z_in` и `f8_last < 0`.
Выход: `|z| < 0.5` или `bars_in_trade ≥ hold`.
**Дефолты:** `z_in=2, hold=18` баров (3 дня), без доп. подтверждения по EMA20. ТФ 4h.

### 12. Slava C2 Local Compression (Слава) ⚠
Портирован из Freqtrade `IStrategy` (`C2LocalCompressionStrategy`).
**Идея:** сжатие волатильности (ATR% локального окна ниже медианы макро-окна, локальный
диапазон намного меньше макро-диапазона) + сильный бычий пробой локального максимума,
всё ещё внутри макро-контейнера. Сигнал подтверждается, если похожий "сырой" сигнал уже
был в предыдущие 72ч. Регим-фильтр по EMA200 у автора выключен по умолчанию.
**Выход:** фиксированно через 60ч, либо раньше (36ч) при просадке ≤ -4% от входа
("age failure"). Стоп -12%. Только лонг.
**Параметры:** ATR(14), local_window=12, macro_window=72, hold=60ч, age_emergency=36ч/-4%,
stop=-12%. ТФ 1h.

### 13. S04 — Turtle System 1 (Леша)
**Идея:** классический пробой канала с выходом по короткому каналу и стопом по ATR.
**Правило:** лонг-вход `close_t > max(high[t-N_in..t-1])`, шорт-вход
`close_t < min(low[t-N_in..t-1])`. Выход из лонга `close_t < min(low[t-N_out..t-1])`,
из шорта — зеркально. Стоп при входе `fill ∓ k×ATR20` (лонг минус, шорт плюс), проверяется
внутри бара по 1h. Без доливок.
**Дефолты:** `N_in=20, N_out=10, k=2`, ATR период 20. ТФ 4h.

### 14. S02 — Time-series momentum (Леша)
**Источник:** Liu, Tsyvinski (2021). **Правило:** `r_L = close_t/close_{t-L} - 1` для
L ∈ {7, 14, 28} дней; `target = mean(sign(r_L))` → значения {-1, -1/3, +1/3, +1}.
**Дефолты:** L=(7,14,28), пересчёт на каждом сигнальном баре. ТФ 1d.

### 15. Gosha Turtle Donchian (Гоша) ⚠
Реконструкция публичного 3Commas/TradingView-скрипта ("Turtle Strategy").
**Правило:** двойной Donchian-пробой. Канал 1 — 20-барный (high/low, без текущего бара).
Канал 2 — тот же Donchian, но построенный по данным со сдвигом ещё на 20 баров назад
("смещённый вправо" канал, фильтр подтверждения). Вход засчитывается только на баре,
где `close` **пересекает** канал 1 (было ≤, стало >), и одновременно уже выше канала 2
(зеркально для шорта). Выход — 10-барный канал в противоположную сторону. Разворот:
пробой в обратную сторону, пока позиция открыта, закрывает и сразу открывает в другую
сторону тем же баром.
**Параметры:** канал1=20, канал2=20 со сдвигом 20, канал выхода=10. ТФ 4h.

### 16. Friend4 Supertrend (Друг4) ⚠
Классический Supertrend: ATR-канал вокруг `(high+low)/2`, направление меняется, когда
цена закрытия пробивает противоположную границу; границы "залипают" — не сужаются
против направления.
**Параметры:** `period=7, mult=2.0`. ТФ 1d.

### 17. S08 — MACD с фильтром EMA (Леша)
**Правило:** `macd = EMA_fast - EMA_slow`, `sig = EMA_signal(macd)`. Пересечение вверх:
`macd[t-1] ≤ sig[t-1]` и `macd_t > sig_t` (вниз — зеркально). Лонг-вход: пересечение
вверх и `close_t > EMA_filter`. Выход — пересечение вниз. Шорт-вход: пересечение вниз и
`close_t < EMA_filter`. На одном баре допустим прямой разворот лонг→шорт.
**Дефолты:** MACD (12,26,9), фильтр EMA(200). ТФ 4h.

### 18. S10 — RSI(2) Коннорса (Леша)
**Правило:** лонг-вход — позиция 0, `RSI2_t < lo` и `close_t > SMA200_t` (фильтр включён
по умолчанию). Выход из лонга: `close_t > SMA5_t` или `bars_in_trade ≥ T`. Шорт-вход —
зеркально (`RSI2_t > hi`, `close_t < SMA200_t`).
**Дефолты:** lo=10, hi=90, фильтр SMA200 включён, T=10. ТФ 4h.

### 19. S06 — Supertrend (Леша)
**Правило:** `hl2 = (high+low)/2`, `bu = hl2 + m·ATR_n`, `bl = hl2 - m·ATR_n`, с ratchet-
логикой полос (не сужаются против направления цены — те же формулы, что у Friend4
Supertrend, только с другими дефолтами и на другом ТФ). `target = +1` при тренде вверх,
`-1` при тренде вниз (всегда в рынке, нет нейтрального состояния).
**Дефолты:** n=10, m=3. ТФ 4h.
