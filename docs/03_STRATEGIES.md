# 03. Спецификация стратегий

Точные правила для реализации. Если правило здесь неоднозначно — не додумывать,
а спросить пользователя и зафиксировать решение здесь и в `JOURNAL.md`.

## 0. Общие соглашения

- Все правила считаются по **закрытию полного бара** сигнального ТФ. Исполнение — на open
  следующего 1h-бара (`01_PROTOCOL`, 5.1).
- «Предыдущие N баров» = бары `t−N … t−1`, **текущий бар не включается**.
- `target` — целевая позиция в долях слота: +1 полный лонг, −1 полный шорт, 0 вне рынка.
- **Окна в днях (day-native)** — стратегии из дневной литературы. На меньшем ТФ окно
  пересчитывается в бары: 12h → ×2, 4h → ×6. Меняется только частота проверки сигнала.
- **Окна в барах (bar-native)** — популярные индикаторные стратегии, их тестируем как принято
  у трейдеров: «20 баров» на любом ТФ.
- Индикаторы: ATR, RSI, ADX — по Уайлдеру (`ewm(alpha=1/n, adjust=False)`);
  EMA — `ewm(span=n, adjust=False)`; std в Боллинджере — `ddof=0`.
- Прогрев: не меньше `3 × самое длинное окно` для EMA/Wilder и `самое длинное окно` для SMA/max/min.
- Первый ТФ в списке — **основной**. Остальные — контрольные.
- Сетки — для walk-forward (`04_OPTIMIZATION.md`). Дефолты — это вариант V0 и всегда входят в сетку.
- Каждая стратегия имеет `version`. Любое изменение логики → новая версия + запись в JOURNAL.

## S01 — Donchian-ансамбль (Zarattini, Pagani, Barbon, 2025)

**Идея.** Несколько пробойных моделей с разными окнами. Итоговая позиция — доля «включённых»
моделей. Ансамбль снижает зависимость от выбора одного окна.

**Окна:** L ∈ {5, 10, 20, 30, 60, 90, 150, 250, 360} дней.

**Для каждого окна L (независимо):**
- `upper_L = max(close[t−L … t−1])`, `lower_L = min(close[t−L … t−1])`, `mid_L = (upper_L + lower_L) / 2`.
- Вход: компонента выключена и `close_t > upper_L` → включить, `stop_L = mid_L`.
- Сопровождение: `stop_L = max(stop_L, mid_L)` на каждом баре.
- Выход: `close_t < stop_L` → выключить. Стоп проверяется **по закрытию** бара, не внутри бара.
- Если истории меньше L — компонента считается выключенной.

**Итог:** `raw = n_включённых / 9` (знаменатель всегда 9).

**Размер по волатильности (как в работе):** `σ = std(дневные лог-доходности за 90 дней) × √365`,
`scale = min(1, vol_target / σ)`, `target = raw × scale`. При `vol_target = null` — `target = raw`.

**Дефолты:** все 9 окон, `vol_target = 0.25`, `vol_window = 90`, ТФ 1d.

**Сетка:** `lookback_set ∈ {all9, short=[5,10,20,30,60], long=[20,30,60,90,150,250,360]}` ×
`vol_target ∈ {0.25, 0.5, null}` × `tf ∈ {1d, 12h}`.

**Примечание.** Правила взяты из пересказа статьи (CXO Advisory). На Этапе 5 сверить с PDF
(SSRN 5209907): тип канала (close или high/low), точное правило трейлинга. Расхождения —
следовать PDF, записать в JOURNAL.

**Ожидание на 2026:** большую часть года вне рынка или с малой позицией. Хороший результат —
малая просадка и отсутствие потерь на обвале, а не высокая доходность.

## S01b — Donchian-ансамбль, зеркальный шорт

То же, что S01, плюс шортовая компонента для каждого окна:
- Вход: `close_t < lower_L` → шорт-компонента включена, `stop_L = mid_L`.
- Сопровождение: `stop_L = min(stop_L, mid_L)`. Выход: `close_t > stop_L`.
- `raw = (n_лонг − n_шорт) / 9`. Размер — как в S01.

Шортовая часть в работе **не проверялась** — это наша гипотеза. В отчётах показывать вклад
лонговой и шортовой частей отдельно.

## S02 — Time-series momentum (Liu, Tsyvinski, 2021)

**Идея.** Если монета росла последние 1–4 недели, дальше она чаще растёт, и наоборот.

**Правило:**
- `r_L = close_t / close_{t−L} − 1` для L ∈ {7, 14, 28} дней.
- `target = mean(sign(r_L))` → значения {−1, −1/3, +1/3, +1}.
- Пересчёт — на каждом сигнальном баре (или раз в неделю — параметр).

**Дефолты:** L = (7, 14, 28), `rebalance = every_bar`, ТФ 1d.

**Сетка:** `lookback_set ∈ {(3,7,14), (7,14,28), (14,28,56), (7), (14), (28)}` ×
`rebalance ∈ {every_bar, weekly}` × `tf ∈ {1d, 12h}`.
`weekly` = решение по закрытию воскресного дневного бара, исполнение в понедельник 00:00 UTC.

**Ожидание:** зарабатывает на длинных направленных движениях (февральский обвал),
теряет в боковике на смене знака.

## S03 — Цена против SMA (Grobys, Ahmed, Sapkota, 2020)

**Идея.** Простейший трендовый фильтр: выше средней — лонг, ниже — шорт.

**Правило:**
- `sma = mean(close[t−n+1 … t])` (текущее закрытие включено — это стандарт для SMA-фильтра).
- `close_t > sma × (1 + band)` → +1; `close_t < sma × (1 − band)` → −1 (режим LS) или 0 (режим LF);
  внутри полосы — сохранить прошлый target.

**Дефолты:** n = 20 дней, `band = 0`, режим LS, ТФ 1d.

**Сетка:** `n ∈ {10, 20, 50, 100}` × `band ∈ {0, 0.01, 0.02}` × `mode ∈ {LS, LF}` × `tf ∈ {1d, 12h, 4h}`.

## S04 — Turtle System 1

**Идея.** Классический пробой канала с выходом по короткому каналу и стопом по ATR.

**Правило:**
- Лонг-вход: `close_t > max(high[t−N_in … t−1])`. Шорт-вход: `close_t < min(low[t−N_in … t−1])`.
- Выход из лонга: `close_t < min(low[t−N_out … t−1])`; из шорта: `close_t > max(high[t−N_out … t−1])`.
- Стоп: при входе `stop = fill ∓ k × ATR20_t` (лонг минус, шорт плюс). Проверка внутри бара по 1h.
- Без доливок и без фильтра «пропускать пробой после прибыльного» (упрощение, зафиксировано).

**Дефолты:** `N_in = 20`, `N_out = 10`, `k = 2`, ATR 20, ТФ 4h.

**Сетка:** `(N_in, N_out) ∈ {(20,10), (55,20)}` × `k ∈ {2, 3}` × `tf ∈ {4h, 1d}`.

**Отличие от оригинала:** вход по закрытию бара рыночным ордером, а не стоп-ордером на уровне.
Это требование протокола (только рыночные ордера).

## S05 — Пробой Боллинджера

**Идея.** Выход цены за полосу — начало движения (трендовая, а не разворотная трактовка).

**Правило:**
- `mid = SMA(close, n)`, `up = mid + k·std(close, n)`, `dn = mid − k·std(close, n)`.
- Лонг: `close_t > up_t` → +1; выход по `exit_rule`. Шорт: `close_t < dn_t` → −1; выход зеркально.
- `exit_rule = mid`: выход из лонга при `close_t < mid_t`. `exit_rule = opposite`: при `close_t < dn_t`.

**Дефолты:** n = 20, k = 2, `exit_rule = mid`, ТФ 1d.

**Сетка:** `n ∈ {20, 50}` × `k ∈ {1.5, 2, 2.5}` × `exit_rule ∈ {mid, opposite}` × `tf ∈ {1d, 12h, 4h}`.

## S06 — Supertrend

**Идея.** Линия на расстоянии m·ATR от цены. Цена выше линии — лонг, ниже — шорт. Всегда в рынке.

**Правило:**
- `hl2 = (high + low) / 2`, `bu = hl2 + m·ATR_n`, `bl = hl2 − m·ATR_n`.
- `fu_t = bu_t, если bu_t < fu_{t−1} или close_{t−1} > fu_{t−1}, иначе fu_{t−1}`.
- `fl_t = bl_t, если bl_t > fl_{t−1} или close_{t−1} < fl_{t−1}, иначе fl_{t−1}`.
- Тренд: был вниз и `close_t > fu_t` → вверх; был вверх и `close_t < fl_t` → вниз.
- `target = +1` при тренде вверх, `−1` при тренде вниз.

**Дефолты:** n = 10, m = 3, ТФ 4h.

**Сетка:** `n ∈ {7, 10, 14}` × `m ∈ {2, 3, 4}` × `tf ∈ {4h, 1h, 12h}`.

**Ожидание:** на 1h с высокой вероятностью проиграет издержкам — это важный контрольный результат.

## S07 — EMA-кросс (golden / death cross)

**Правило:** `EMA_fast > EMA_slow` → +1, иначе −1 (режим LS) или 0 (режим LF).

**Дефолты:** (50, 200), режим LS, ТФ 4h.

**Сетка:** `(fast, slow) ∈ {(20,50), (20,100), (50,200)}` × `mode ∈ {LS, LF}` × `tf ∈ {4h, 1d}`.

## S08 — MACD с фильтром EMA

**Правило:**
- `macd = EMA_fast − EMA_slow`, `sig = EMA_signal(macd)`.
- Пересечение вверх: `macd_{t−1} ≤ sig_{t−1}` и `macd_t > sig_t`; вниз — зеркально.
- Лонг-вход: пересечение вверх и `close_t > EMA_filter`. Выход: пересечение вниз.
- Шорт-вход: пересечение вниз и `close_t < EMA_filter`. Выход: пересечение вверх.
- На одном баре допустим разворот лонг → шорт, если выполнены условия шорта.

**Дефолты:** (12, 26, 9), фильтр EMA 200, ТФ 4h.

**Сетка:** `macd ∈ {(12,26,9), (8,21,5)}` × `filter ∈ {EMA200, EMA100, none}` × `tf ∈ {4h, 1h}`.

## S09 — Volatility breakout (Larry Williams)

**Идея.** Если внутри дня цена ушла от открытия дальше, чем на долю вчерашнего диапазона,
движение продолжится до конца дня.

**Правило (день D, UTC):**
- `O_D` = open первого 1h-бара дня (00:00). `R = high_{D−1} − low_{D−1}` по полному дневному бару.
- `up = O_D + k·R`, `dn = O_D − k·R`.
- На закрытии каждого 1h-бара дня (кроме последнего, 23:00–00:00): если сегодня ещё не было
  входа и `close_h > up` → target +1; если `close_h < dn` → target −1 (в режиме LS).
- Не больше одного входа в день. На закрытии бара 23:00–00:00 → target 0
  (выход на open 00:00 следующего дня).
- Фильтр тренда (параметр): лонги только если `close_{D−1} > SMA5d`, шорты — только если ниже.

**Дефолты:** k = 0.5, режим LS, без фильтра.

**Сетка:** `k ∈ {0.3, 0.5, 0.7}` × `mode ∈ {LS, long_only}` × `trend_filter ∈ {none, sma5d}`.

**Отличие от оригинала:** вход по подтверждению закрытием 1h-бара, а не касанием уровня
(только рыночные ордера). Это делает вход чуть хуже оригинала — честнее для нашей песочницы.

## S10 — RSI(2) Коннорса

**Идея.** Очень короткая перепроданность внутри тренда откатывается.

**Правило:**
- Лонг-вход: позиция 0, `RSI2_t < lo` и (`close_t > SMA200_t`, если фильтр включён).
- Выход из лонга: `close_t > SMA5_t` или `bars_in_trade ≥ T`.
- Шорт-вход: `RSI2_t > hi` и (`close_t < SMA200_t`). Выход: `close_t < SMA5_t` или тайм-стоп.

**Дефолты:** lo = 10, hi = 90, фильтр SMA200, T = 10, ТФ 4h.

**Сетка:** `(lo, hi) ∈ {(5,95), (10,90), (15,85)}` × `filter ∈ {sma200, none}` × `T ∈ {5, 10, 20}` × `tf ∈ {4h, 1h}`.

**Ожидание:** для крупных ликвидных монет разворотные эффекты слабые, а на 1h издержки
съедают небольшие движения. Контрольная стратегия.

## S11 — Возврат к Боллинджеру в боковике (+ ADX)

**Правило:**
- Торгуем только при `ADX14_t < adx_thr` (нет сильного тренда).
- Лонг-вход: `close_t < dn_t` (BB 20, k). Выход: `close_t ≥ mid_t`, стоп `fill − s·ATR14`
  (внутри бара по 1h), тайм-стоп 20 баров.
- Шорт — зеркально от верхней полосы.

**Дефолты:** `adx_thr = 20`, k = 2, s = 2, ТФ 4h.

**Сетка:** `adx_thr ∈ {15, 20, 25}` × `k ∈ {2, 2.5}` × `s ∈ {1.5, 2, 3}` × `tf ∈ {4h, 1h}`.

## S12 — Контртренд по экстремальному фандингу

**Идея.** Экстремально высокий фандинг — перегруженные лонги, чаще перед падением;
экстремально отрицательный — перегруженные шорты.

**Подготовка фандинга:**
- Нормировать к 8-часовому эквиваленту: `f8 = funding_rate × (8 / interval_hours)`
  (у части монет Binance интервал 4h).
- На закрытии 4h-бара используются только отметки фандинга **строго раньше** момента закрытия.
  Отметка ровно в момент закрытия учитывается на следующем баре — консервативно, без риска подглядывания.
- `z = (f8_last − mean(f8 за 30 дней)) / max(std(f8 за 30 дней), 0.00005)`.
  Нижняя граница std защищает от деления на почти ноль, когда фандинг «прибит» к базовой ставке.

**Правило:**
- Шорт-вход: `z > z_in` и `f8_last ≥ 0.0002` (вдвое выше базовой ставки 0.01%).
- Лонг-вход: `z < −z_in` и `f8_last < 0`.
- Выход: `|z| < 0.5` или `bars_in_trade ≥ hold`.
- Подтверждение (параметр): для шорта `close_t < EMA20_t`, для лонга `close_t > EMA20_t`.

**Дефолты:** `z_in = 2`, `hold = 18` баров (3 дня), без подтверждения. ТФ 4h.

**Сетка:** `z_in ∈ {1.5, 2, 2.5}` × `hold ∈ {6, 18, 30}` × `confirm ∈ {none, ema20}`.

## S13 — Кросс-секционный моментум (Liu, Tsyvinski, Wu, 2022)

**Только портфельный режим.**

**Правило:**
- Ребаланс раз в неделю: решение по закрытию воскресного дневного бара, исполнение в понедельник 00:00 UTC.
- `score_i = close_{t−skip} / close_{t−L} − 1` для каждой монеты пула с полной историей L.
- Лонг — k лучших (target +1), шорт — k худших (target −1), остальные 0.
- Если монет с полной историей меньше 2k — позиций на эту неделю нет.

**Дефолты:** L = 21 день, k = 3, skip = 0.

**Сетка:** `L ∈ {7, 14, 21, 28}` × `k ∈ {2, 3}` × `skip ∈ {0, 1}`.

**Отбор монет (V2) не применяется** — пул сам по себе вход стратегии.

## O1 — Надстройка: фильтр режима BTC

- `btc = последнее полное дневное закрытие BTCUSDT`, `btc_sma = SMA(btc, sma_days)`.
- Если `target > 0` и `btc ≤ btc_sma` → `target = 0`. Если `target < 0` и `btc ≥ btc_sma` → `target = 0`.
- **Применяем к:** S01b, S02, S06 (список фиксирован заранее).
- **Сетка:** `sma_days ∈ {50, 100, 200}`. Дефолт 50.

## O2 — Надстройка: таргетирование волатильности

- `σ = std(дневные лог-доходности монеты за W дней) × √365`, `scale = min(1, σ* / σ)`, `target ×= scale`.
- **Применяем к:** S02, S03 (у S01 это уже встроено).
- **Сетка:** `σ* ∈ {0.25, 0.5, 0.75}` × `W ∈ {30, 90}`. Дефолт σ* = 0.5, W = 90.

Варианты с надстройками получают ID вида `S02+O1` и учитываются в реестре как отдельные испытания.
В лидерборде они показываются в отдельном разделе «эксперименты с надстройками».
